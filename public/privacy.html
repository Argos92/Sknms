Политика конфиденциальности

Приложение «Скинемся»
Последнее обновление: 25 июня 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает порядок сбора, хранения, использования и защиты персональных данных пользователей приложения «Скинемся». Используя приложение, пользователь соглашается с настоящей Политикой.

2. Какие данные мы собираем

  • адрес электронной почты;
  • имя пользователя;
  • номер телефона;
  • уникальный идентификатор пользователя (UID);
  • фотография профиля;
  • технические журналы ошибок;
  • данные аналитики использования приложения.

Адрес электронной почты подтверждается при регистрации. Номер телефона используется по инициативе пользователя и не подтверждается.

3. Какие данные создаются пользователем

  • названия событий (эвентов);
  • обложки событий;
  • списки участников;
  • записи о расходах;
  • распределение расходов между участниками;
  • отметки о подтверждении взаиморасчетов.

4. Для чего используются данные

  • регистрация и вход в аккаунт;
  • отображение имени и фотографии участникам события;
  • расчет взаимных задолженностей;
  • синхронизация данных между устройствами;
  • восстановление доступа к аккаунту;
  • повышение стабильности приложения и устранение ошибок.

Приложение не осуществляет денежные переводы, не принимает платежи и не хранит банковские карты или платежные реквизиты пользователей.

5. Передача данных третьим лицам

Данные передаются только сервисам, необходимым для работы приложения:

  • Supabase — авторизация пользователей и хранение данных;
  • сервисы аналитики и сбора отчетов об ошибках.

Продажа персональных данных третьим лицам не осуществляется.

6. Хранение данных

Данные хранятся в инфраструктуре Supabase Cloud и на собственном сервере Selectel. Информация хранится до удаления аккаунта пользователем либо до получения запроса на удаление через службу поддержки.

7. Защита информации

  • авторизация пользователей через Supabase;
  • разграничение доступа посредством Row Level Security (RLS);
  • использование защищенного соединения HTTPS.

8. Удаление аккаунта и данных

Пользователь может удалить аккаунт через приложение либо обратиться в службу поддержки. После обработки запроса персональные данные и связанные с ними сведения удаляются, за исключением случаев, когда их хранение требуется законодательством.

9. Права пользователя

  • получить информацию о своих данных;
  • изменить персональные данные;
  • удалить аккаунт;
  • отозвать согласие на обработку персональных данных, прекратив использование приложения и запросив удаление аккаунта.

10. Изменение политики

Политика может обновляться. Актуальная версия всегда публикуется на данной странице.
